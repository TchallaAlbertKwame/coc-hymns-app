## 🆕 What's New in V3.0.2

- 💖 **Seamless Worldwide Giving**: Convenient support for contributions and donations via PayPal, allowing members and supporters worldwide to give easily using Debit/Credit Cards or PayPal balance.
- 🖥️ **Secondary Screen & Projector Detection**: Native multi-monitor positioning on Desktop and Web (Window Management API) so the presentation window opens directly on the projector without having to drag it across screens.
- 📱 **iOS Stage Mode**: Clean, distraction-free edge-to-edge presentation for AirPlay and HDMI mirroring with tap-to-advance controls.
- 📖 **Centered Scripture & Version Badges**: Perfectly centered horizontal badges displaying book, chapter, verse, and version (e.g. `GENESIS 45:11 [NKJV]`).
- 📚 **Dynamic Hymn Books Library**: Real-time integration of Dangme and user-customized books in the Live Projection source list.
- 🛡️ **Bible Error Recovery**: Friendly user-facing error message with dedicated reload button across all platforms.
- 🎵 **Web Audio & Presentation Parity**: YouTube playback and hymn sharing on the Web.
