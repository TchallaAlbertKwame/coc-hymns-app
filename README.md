# COC Hymns App  

COC Hymns App is a mobile application designed to provide seamless access to a collection of Church of Christ hymns. Whether you’re offline or online, you can browse, search, and sing along with your favorite hymns effortlessly.  

## Features  
✅ Offline access to hymns (Android)  
✅ Web app for iOS users  
✅ Search functionality for quick hymn lookup  
✅ User-friendly and intuitive interface  
✅ Regular updates and improvements  

## Installation Guide  

### **📱 For Android Users**  
1. Download the latest APK file from the **[Releases](https://github.com/TchallaAlbertKwame/coc-hymns-app/releases)** section of this repository.  
2. Open the downloaded APK file.  
3. If prompted, enable "Install from Unknown Sources" in your device settings.  
4. Tap **Install** and wait for the process to complete.  
5. Once installed, open the app and enjoy the hymns.  

### **🍏 For iOS Users**  
The COC Hymns App is available as a web app. Follow these steps to access and install it:  

1. Open the web app: **[COC Hymns Web App](https://cochymn.web.app/)**  
2. Follow the step-by-step installation guide here: **[iOS Installation Guide](https://iosinstallation.netlify.app/)**  
3. Once installed, you can access the app directly from your home screen like a native application.

## 🛠 Troubleshooting  

### **Android Issues**  
- **App not installing?**  
  - Ensure you have enabled "Install from Unknown Sources" in your phone settings.  
  - Check if an older version of the app is installed. Uninstall it and try again.  
  - Make sure you have enough storage space on your device.  

- **App crashing or freezing?**  
  - Restart your phone and try reopening the app.  
  - Ensure you have the latest version of the app. Download updates from the **[Releases](https://github.com/TchallaAlbertKwame/coc-hymns-app/releases)** page.  
  - Clear the app cache from your phone settings.  

### **iOS Issues**  
- **Web app not installing on home screen?**  
  - Ensure you are using Safari, as other browsers may not support web app installation.  
  - Follow the installation steps carefully in the **[iOS Installation Guide](https://iosinstallation.netlify.app/)**.  
  - If the "Add to Home Screen" option is missing, check if Safari’s JavaScript is enabled in settings.
 
- **Cannot scroll on latest iOS?**
   - use two fingers  for the scrolling

## ❓ Frequently Asked Questions (FAQs)  

### **1. Is the COC Hymns App free to use?**  
Yes! The app is completely free to download and use.  

### **2. Do I need an internet connection to use the app?**  
- **Android users** can access hymns offline after installation.  
- **iOS users** require an internet connection to access the web app.  

### **3. Will the app receive updates?**  
Yes, we plan to release updates with improvements, bug fixes, and additional features. Keep an eye on the **[Releases](https://github.com/TchallaAlbertKwame/coc-hymns-app/releases)** section for updates.  

### **4. Can I suggest new features or report issues?**  
Absolutely! We welcome feedback. You can create an issue in this repository to report a bug or suggest a new feature.  

### **5. Is there an iOS native app planned?**  
Currently, the app is available as a web app for iOS users. A native iOS app may be considered in the future.
